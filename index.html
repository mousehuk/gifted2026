🚀 GitHub Pages 깃허브 배포 가이드

  1. GitHub 저장소 생성: 깃허브(GitHub)에서 새 Repository를 Public으로 생성합니다.
  2. 파일 업로드: 본 웹앱 코드를 index.html 파일로 저장하여 업로드합니다.
  3. Pages 설정: 저장소 Settings > Pages 메뉴로 이동합니다.
  4. 배포 완료: Branch를 main / root로 설정 후 저장하면 무료 웹 URL이 생성됩니다!
