설문 미리보기

깃허브 페이지스(GitHub Pages) 배포 가이드

본 웹앱은 단일 HTML 파일(Single File)로 제작되어 별도의 빌드 과정 없이 GitHub에 업로드하여 즉시 웹사이트로 배포할 수 있습니다.

1단계: 파일 저장

현재 웹페이지 코드를 복사하여 컴퓨터에 index.html 파일명으로 저장합니다.

2단계: GitHub 새 Repository 생성

GitHub에 로그인 후 새 Repository(저장소)를 생성합니다. (Public 공개 설정 필수)

3단계: 파일 업로드

Repository 메인 화면에서 [Add file] > [Upload files]를 클릭하여 저장해둔 index.html 파일을 업로드하고 Commit 합니다.

4단계: GitHub Pages 활성화

Repository [Settings] > [Pages] 메뉴로 이동한 뒤, Build and deployment의 Branch를 main (또는 master) 및 / (root)로 설정하고 Save를 누릅니다.

배포가 완료되면 1~2분 뒤 GitHub이 제공하는 주소(https://사용자명.github.io/저장소명/)로 접속하여 전 세계 사람들과 설문조사를 진행할 수 있습니다!
